KYRO UPDATE — QUICK START

1. Keep a backup of your current KYRO repository before replacing files.
2. Upload index.html, style.css, and script.js from this folder to the ROOT of your existing KYRO GitHub repository.
3. Commit the changes. Cloudflare Pages should redeploy automatically.

WHAT'S NEW
- KYRO Music now has SoundCloud and Spotify tabs.
- Paste a public SoundCloud track or playlist URL to load its official embed.
- Paste a Spotify track, album, playlist, show, or episode URL to load its official embed.
- New original Life Mode simulator: age up, make choices, manage health/happiness/smarts/money, and build a timeline.
- Existing dashboard, themes, profile, and three built-in mini-games are included.

IMPORTANT
- This is a full replacement set for the starter version. Back up your repository first.
- SoundCloud/Spotify playback depends on each service's embed availability, track permissions, account requirements, and network access. This does not bypass school/work network restrictions.
- Profile, theme, and Life Mode save only in the current browser session/device where applicable. Online accounts/cloud saves are not included yet.
- Life Mode is an original lightweight life simulator, not a copy of BitLife.
